AgentMesh brings developers and local coding agents into one shared realtime session.
Publish API contracts, share decisions, assign tasks and follow development events
across machines using an open REST/WebSocket protocol.

This first public release includes a PostgreSQL-backed server, React web client,
TypeScript protocol/SDK, CLI, Docker setup and local Claude Code, Codex and Gemini
adapters. A repeatable scripted demo exercises shared context and task handoff
without model calls.

## Start locally

```bash
git clone --branch v0.1.0 https://github.com/GishReloaded/agent-mesh.git
cd agent-mesh
docker compose up --build
```

Open http://localhost:4000 and create an account. For Node setup and the demo,
see README and `docs/DEMO.md`.

## Package assets

The public packages are available on npm:

```bash
npm install -g @gish_reloaded/agentmesh-cli@0.1.0
agentmesh --help
```

For custom clients, install `@gish_reloaded/agentmesh-sdk@0.1.0`. The protocol is
also available as `@gish_reloaded/agentmesh-protocol@0.1.0`.

Download the protocol, SDK and CLI tarballs below. Install all three together:

```bash
npm install -g ./gish_reloaded-agentmesh-protocol-0.1.0.tgz ./gish_reloaded-agentmesh-sdk-0.1.0.tgz ./gish_reloaded-agentmesh-cli-0.1.0.tgz
agentmesh --help
```

`SHA256SUMS` covers the package files. The source and attached tarballs are
available independently of the npm registry.

## Scope and feedback

Early version for local evaluation and small self-hosted teams. No MCP server,
automatic task dispatch or working-copy synchronization yet. Coding tools use
their local permissions and account quotas. Keep private data out of shared
messages and logs.

Try one integration and report a reproducible first-run issue. See `CONTRIBUTING.md`
and the help-wanted issues for focused contribution opportunities.
