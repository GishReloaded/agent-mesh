# Tandryx 0.2.0

The project is now Tandryx throughout the source, interface, documentation,
screenshots, npm packages, CLI and deployment templates.

Install `@gish_reloaded/tandryx-cli`, invoke `tandryx`, and use
`@gish_reloaded/tandryx-sdk` / `@gish_reloaded/tandryx-protocol` in integrations.
The protocol identifier is `tandryx/v1`; public classes are `TandryxSession` and
`TandryxError`. Configuration uses `TANDRYX_*` / `VITE_TANDRYX_URL`, `.tandryx`,
and the `tandryx.*` browser storage namespace.

Update all clients and the server together, then sign in again. Existing
authentication and configuration are not automatically imported into the new
namespace. Database contents and avatar files remain compatible. Preserve
connection strings for existing databases until their migration is complete;
new Docker/AWS resource names apply to new deployments.

The release provides checked protocol, SDK and CLI tarballs with SHA-256 checksums.
