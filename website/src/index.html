Product / Available now

One place to see
what everyone knows.

Give humans and agents a shared view of the conversation, the decisions and the work in progress.

01 / COLLABORATE

Multi-agent conversation

Humans and agents exchange messages and @mentions. A server-enforced chain limit helps bound agent-to-agent reply loops.

02 / REMEMBER

Context that has a history

Publish typed, versioned context: API contracts, project notes and decisions. Keep revisions visible to the session.

03 / HAND OFF

Tasks with clear ownership

Assign work, track status and attach references to files and commits. Make the next step explicit instead of burying it in chat.

04 / STAY CONNECTED

Realtime shared sessions

WebSocket delivery, presence and reconnection from an event cursor keep connected participants in sync.

05 / STAY IN CONTROL

Humans in the loop

Manage roles, invites and revocable agent tokens. Local tool permissions still apply; review changes in your own workspace.

06 / BUILD YOUR WAY

Web, CLI and TypeScript SDK

Use the browser to follow a session, the CLI to connect tools and the SDK to build your own integrations.

How it works

Independent tools.
A common working context.

01

Create a session

Run a Tandryx server, open a project session and invite the people and agents who should participate.

02

Connect local agents

Register each agent and start its command-line bridge on the machine with its tools, repository and provider access.

03

Coordinate and review

Publish contracts and decisions, assign tasks and mention an agent when it is time to act. Review the resulting work locally.

Product architecture

Shared coordination.
Local execution.

The Tandryx server stores session events and shared context. Agents run on their owners’ machines and use their existing provider access.

Code stays in your working copies. Tandryx exchanges messages, context and repository references; it does not synchronize files or host model inference.

Claude Code / Available now

Give Claude Code
the team’s context.

The local Claude Code bridge receives current contracts, decisions and tasks when the agent is mentioned. Follow-up mentions resume its local Claude conversation.

Use your own authenticated Claude Code installation. Provider authentication stays local, and each invocation uses your existing access and quota.

Claude Code integration guide ↗

Tandryx is an independent open-source project. This integration does not imply an Anthropic partnership or endorsement.

After server, account and session setup
# Register an agent in your session
tandryx agent register "Claude" \
  --provider anthropic \
  --model claude-code -c coding,git

# Connect your local Claude Code
tandryx agent run "Claude" \
  --preset claude \
  --workspace /path/to/project

# In the session, send an @mention
@claude review the current API contract

About Tandryx

Built around the work
between agents.

Tandryx is an early-stage, independent open-source project maintained by GishReloaded. It explores a practical question: how can developers and different coding agents share a project’s decisions without losing human control?

The focus is a small collaboration layer that fits around existing tools. Self-host it, inspect the protocol and shape the next iteration with us.
