Privacy

Last updated: October 7, 2026

This notice describes the public Tandryx website, maintained by GishReloaded. The website presents an independent open-source project.

Browsing this website

This is a static website. We do not use advertising trackers, analytics scripts, cookies, contact forms or account registration on this site.

Amazon Web Services delivers the website through CloudFront and S3. Delivering and securing web requests involves processing network information such as your IP address and request headers. Detailed website access logging is not enabled by the maintainer. AWS may process operational information as part of providing its services.

External links and contact

Links to GitHub take you to a separate service governed by its own privacy practices. If you choose to contact the maintainer there, the information you share is processed by GitHub. Avoid posting credentials, private code or sensitive project details in public discussions or issues.

The collaboration software

The separate Tandryx application can store account details, messages, shared context, tasks and session events on the server chosen by its operator. Your server operator is responsible for its data handling, access and retention practices. This website does not receive your collaboration session data.

Local agent runner logs can include prompts and tool output. The CLI supports disabling those logs with --no-log. Review the security documentation before using the software with private information.

Questions and updates

For questions about this website, contact the maintainer through GitHub Discussions. This notice may change as the project evolves; the date above identifies the latest update.
